# 设计与审片（2.12）

制作工具新增「设计与审片」。适合先建立设计方向，再逐页修订的制作流程。

- **设计规范**：编辑叙事、品牌简洁、醒目海报。保存背景、文字/辅助/强调色、标题与正文字体、字号阶梯和安全边距。绑定主标题、正文、注释、强调角色；新文字自动继承，显式参数优先。支持 `setDesign {preset|design,ids?,time?}` 自定义规范。
- **版式**：编辑版、图文分栏、海报、卡片。按选中元素及完整分组操作；没有选择时使用播放头场景。横竖屏分别安排图文区；替换分组布局但保留其他分组状态。`applyDesignLayout {layout,ids?,time?}`。
- **中文排版**：`typesetText {ids?,time?,balance?}`。保护已有换行和富文本，标题断行避开行首/行尾禁则；显示时支持中英细空格、数字单位连排、严格换行和平衡行宽。逐字/逐词动画、计数器和未完成的揭示保留原字符序列，避免改变动画时序。
- **方案对比**：用相同源内容生成三个真实帧缩略图。只有点击采用才修改时间线，可撤销。生成不是美学评分，也不能保证复杂工程无需手工调整。
- **规则检查**：安全边距和小字号提示，独立于已有「成片检查」。
- **AI 视觉审片**：将请求插入当前对话，模型调用 `djian_design_review inspect` 获得带时间点的实际画面联络图；看图后以 `submit {baseRev,items:[{message,time,ops}]}` 提交有依据的视觉属性修改。制作工具刷新建议、选择条目、查看修改前后并采用。禁止建议改写内容、删元素、改时长或执行任意系统操作。

方案和建议暂存在引擎内存，最多 24 组，30 分钟后或引擎重启后需重新生成；工程版本变化后拒绝应用，防止覆盖后续编辑。背景规范影响整个项目。静态取帧无法代替完整播放，复杂动画、遮罩、长文本还需人工检查。

验证：`npm run check`、`npm test`、`node tests/integration/design-ui.mjs`。示例 `examples/design-studio.json`；截图 `docs/screenshots/43-design-studio.png` 和 `44-design-review.jpg`。
