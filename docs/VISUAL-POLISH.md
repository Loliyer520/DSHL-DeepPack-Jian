# 视觉增强与曲线编辑（2.5.0）

- **内阴影/内发光**：外观面板的每层阴影可切换「内阴影」。`shadow:{color:'#000',blur:12,opacity:.4,inset:true}`；可与外阴影混用，总计最多 8 层。
- **渐变描边**：形状描边颜色支持线性或径向渐变，格式与填充一致。线条、箭头和箭头端点也支持。图片边框和文字描边仍使用纯色。
- **毛玻璃**：外观面板可启用背景模糊、饱和度、亮度、染色、透明度、圆角与亮边。启用时将形状填充设为透明；不透明填充会遮住玻璃。前景文字保持清晰。组合的透明度、滤镜或遮罩可能限制浏览器可采样的背景范围。
- **共享元素**：前后两个元素设置相同共享标识，前一个结束时间与后一个开始时间相接，即自动过渡。由后一个元素设置时长和缓动；支持位置、大小、旋转及外观的平面过渡。手动 morph 优先，歧义匹配、3D 元素、镜头变换覆盖的场景、连接器、带遮罩或错峰的组合跳过自动过渡。建议使用明确宽高；自动文字尺寸、非等比缩放与剪切可能只能近似过渡。过渡元素显示在普通元素上方。
- **曲线编辑器**：片段/元素/组合动画面板选择通道，拖动关键帧修改时间与值，双击空白添加；可精确输入、删除、在播放头添加。时间按帧吸附。缓动选择「贝塞尔曲线」后可拖动两个控制点或输入数值，支持超调；弹簧参数继续可用。

时间线格式 v12，可读取旧项目。所有修改通过原有 ops 保存，可撤销并供 AI 读取。

示例：[visual-polish.json](../examples/visual-polish.json)。验证：`npm test`、`npm run check`、`npm run test:polish`。像素测试验证内阴影边界、渐变描边、真实背景模糊及共享元素的位置连续性。
