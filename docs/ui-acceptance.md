# 剪辑面板验收记录

对应分支 `optimize/phase0-5`。在真实 DSH 0.2.0-rc.2 web 宿主中（`npm run serve:dsh`，本地假模型）逐项操作确认。截图见 [screenshots/](screenshots/)，由无头 Edge 经 CDP 以 1440×900@1.5x 采集。

| 项目 | 结果 |
| --- | --- |
| 右侧栏引导页出现「D剪 剪辑」「资源库」两个入口，打开后连接引擎显示「已同步」 | 通过 |
| 宽度自适应：右侧栏常规宽度为窄布局（属性/素材/动态为底部抽屉），宿主全屏后为中/宽布局 | 通过 |
| 面板「全屏编辑」按钮切换宿主右侧栏全屏 | 通过 |
| 素材：缩略图、时长/尺寸/引用次数，「+」与双击添加到主轨/音频轨 | 通过 |
| 时间线：视频胶片缩略图、音频波形、主轨拖动重排、选中后裁剪手柄 | 通过 |
| 属性：拖动数值实时预览、松手提交；◆ 在播放头打关键帧，换位置改值自动打帧，片段上显示关键帧标记 | 通过（修复了拖动预览导致不提交的问题） |
| 对话里让 AI 加字幕：经 host-bridge 原生工具写入，面板实时出现 | 通过 |
| AI 工作状态胶囊、「动态」里 AI 修改的定位与单独撤销 | 通过 |
| 导出：分辨率/画质选择、进度、完成后下载 | 通过（修复了精简版 FFmpeg 下编码器自检误报） |
| 宿主深色主题下主按钮、选中态的对比度 | 通过（宿主品牌色为近白色，改用宿主按钮令牌） |
| 宽/中布局下属性面板很长时，时间线仍完整可见 | 通过（修复：侧栏参与网格行尺寸计算把时间线挤出可视区） |
| 右键菜单（时间线、素材、更多）背景与字体 | 通过（修复：菜单经 portal 挂在面板外，拿不到设计令牌，背景透明） |
| 预览不因被中断的媒体请求误报「无法加载素材」 | 通过（修复：先用 HEAD 确认素材确实读不到再提示） |
| 刷新后「动态」仍能看到并撤销之前的 AI 修改 | 通过（新增：连接时补回最近 40 次修改） |
| DSH「轨迹」里可见注入给模型的 `<editor-activity>`，时间为本地时间 | 通过（修复：原为 UTC） |
| 导出的 MP4 与预览一致（标题动画、画中画圆角投影、关键帧缩放旋转、AI 修改后的字幕样式） | 通过 |

自动化覆盖见 `tests/`：面板 store 对接真实引擎的协同测试（乐观更新、与 AI 并发、撤销只回退自己的修改、单独撤销 AI 修改、离线批次幂等补发）、时间线版面、字幕文件、引擎接口与安全校验、宿主集成（`npm run test:host`）。
