# D剪 3.2.0

视频可作为原生元素与文字、图片、图形统一排序，支持 AI 新增和修改、源入点、倍速、原声、定格、适应方式与圆角，沿用位置、组合、动画和遮罩功能。

- 视频轨道和元素导出采用确定性源帧提取，减少浏览器 seek 导致的错帧风险。
- 内嵌合成预览复用解码器并按累计速度连续播放，修复暂停后快速跳转时最新定位可能被旧 seek 覆盖的问题。
- 预览优先使用已生成代理；新版代理缩短关键帧间隔，改进跳转。视频运动模糊预览减少重复解码，正式导出保留采样。
- 源视频纳入素材依赖、AI 上下文、工程打包、重链接、声音映射和导出预检；默认导出并发上限降为 4。
- 时间线格式升至 v22，内部包升至 0.4.0，旧工程自动迁移。

详见 [使用说明](VIDEO-ELEMENTS.md)。大分辨率或复杂源编码仍建议先生成预览代理；预览速度受硬件和编码影响。
