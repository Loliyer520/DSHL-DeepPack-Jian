# 布局、路径与运动模糊（2.7.0）

## 运动模糊

元素样式页、组合属性页可开启运动模糊，设置 2–16 次采样和 0–720 度快门。180 度采样前半帧，360 度采样前一帧；0 度保持清晰。每次采样重新求值位移、旋转、路径和组合动画，以隔离的加法合成求平均，静止物体不会因此变暗。完全按时间计算，拖动播放头和导出无需前一帧状态。

当前支持原生元素和组合。组模糊开启时，成员不再次重复采样。不会复制视频或音频播放。采样越多预览和导出越慢；不建议与背景毛玻璃混用，因为样本透明度会限制浏览器的背景采样范围。自动共享元素转场会跳过带运动模糊的对象。

## 可视化路径编辑

形状的自由路径、元素运动路径、自定义遮罩都提供节点编辑区域。蓝点是锚点，紫点是控制柄，可拖动和用方向键微调（Shift 加大步长）；双击空白可追加节点，按钮可在线段中间加点、删除节点或闭合路径。移动锚点会带动相邻控制柄，镜像选项保持两侧控制柄对称。

路径数据仍为标准 SVG。圆弧等命令编辑时转换为三次贝塞尔，便于统一编辑；曲线细分保留原几何。支持预览、提交与撤销。

## 内容尺寸与组布局

文字、带字形状可开启「随文字调整尺寸」，设置最小/最大宽度和内边距。引擎按字号、字符宽度、换行计算外框，修改文字或字号后同步更新。当前使用保守字宽估计，特殊字体、富文本与复杂字距可适当增加内边距，或关闭后手工调整。

组合支持横排、竖排、网格，设置位置、间距、内边距和对齐方式。没有固定宽高时外框包裹内容；固定宽高可居中、靠边、均分或拉伸。网格可指定列数。「随内容伸缩的背景」引用同组形状，将其尺寸与布局外框绑定。背景本身不占排列位置；需要放在内容后方。

按图层顺序布局。跟随对象、连接器、镜头和 `layoutExclude:true` 的成员不参与流式排列。所有时段的组成员共用布局，不会随播放头临时挤动。布局计算结果保存在元素 x/y/w/h 中，画布选择框、AI JSON 和导出一致；成员动画以新位置为起点。关闭布局后保留最后的位置。超出时间线允许坐标范围时拒绝修改，避免保存无效项目。

时间线格式 v14，旧项目自动读取。例子：[layout-path-blur.json](../examples/layout-path-blur.json)。测试：`npm test`、`npm run check`、`npm run test:layout-blur`。
