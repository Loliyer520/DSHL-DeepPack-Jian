# D剪 3.2.1

视频素材体检、自动预览代理与导出前解码检查。

- 素材库显示编码、帧率、可变帧率提示、HDR/高位深提示和旋转信息；工程工具支持重新检查视频。
- 新增按项目启用的“新视频导入后自动生成代理”，覆盖尚未插入时间线的素材；代理任务限制并发，支持取消排队，运行任务完成后丢弃取消的结果。
- 嵌套预览暂停不可见视频，并合并部分定位请求，减少无效解码。
- 导出前实际抽查视频首、中、尾帧，解码失败时报告素材与时间点并阻止导出；最多检查 100 个唯一视频。

验证：208 项单测、类型检查、浏览器预览、视频画面与音频导出、坏素材拦截、工程工具 UI 和整合包加载。

说明：VFR 和 HDR 为元数据提示；抽帧检查不等于完整视频逐帧扫描。此版未提供兼容副本转码或 HDR 色调映射。代理仅用于预览，导出使用原素材。
