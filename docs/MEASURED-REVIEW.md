# 实测审片与设计保护（2.14）

「制作工具 → 设计与审片」新增三个入口：

- **手工设计保护**：选择元素后保护位置、尺寸、字号、字体、颜色或换行。自动设计规范、主题、版式、画布适配、AI 修改与审片建议避开受保护字段；属性面板仍可手动修改。锁随工程保存，可撤销。锁可能使自动布局无法满足所有间距约束，需要结合审片处理。
- **实测当前画面**：使用导出同一套 Chromium、实际加载的字体和 DOM 文字边界，检查溢出、文字相交与出界。字号修正通过浏览器重新排版搜索，而不是只按字符数估算；候选在最小字号以内仍不能容纳时保留为人工处理项。检查与预览不修改工程。
- **检查动态画面**：在入场、退场、关键帧与转场附近最多抽样 24 帧，检查可见内容出界、文字相交、采样间可见性跳变和估计可读时间。返回抽样时间与截断信息，支持看联络图逐项核对。

审片卡片包含目标元素、时间、问题依据和区域标记。可定位到时间线，查看问题区域，忽略或恢复建议，预览所选修改再采用。采用进入普通撤销/重做。旧建议不能覆盖新版本；「修复后复查」会在当前版本重新测量原时间点。

## AI 工具

`djian_design_review` 支持 `inspect`、`measure`、`motion`、`submit`。`measure` 接受 `time` 与 `ids`；`motion` 接受 `ids`，以 `sheet:0…3` 查看不同联络图。返回实际边界、建议和版本号。`submit` 可附 `id`、`region:{x,y,w,h}`（归一化画布区域）、`evidence`，保留有画面依据的理由。

通过 `updateOverlay.patch.designLocks` 设置保护类别：`position`、`size`、`fontSize`、`fontFamily`、`color`、`lineBreaks`；传 `null` 解除全部保护。AI 不能直接修改已受保护的字段，需先由用户解除对应保护。

## 检查边界

浏览器边界是几何证据，不是像素级遮挡推理。蒙版、玻璃、3D、旋转、运动模糊及有意叠字仍需人工确认。动态结果是离散抽样，快速闪烁可能遗漏，可见性跳变也可能是有意设计；可读时间按抽样与字符数估计，不自动改时长。只有静态、无组合变换的安全目标才生成位置或字号修正，其余提供证据和人工处理项。
