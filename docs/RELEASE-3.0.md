# D剪 3.0.0

3.0.0 集中发布前面各轮开发的功能。整合包版本为 3.0.0，时间线格式为 v20；内部 vendor 包继续采用独立版本号。旧时间线可迁移读取，高于引擎支持格式的项目仍按只读处理。

## 3.0.1 启动修复

- 将轨道遮罩所需的浏览器静态 SVG 渲染器打入时间线面板，修复 DSHL 模块表没有 `react-dom/server` 时整个面板加载失败的问题。
- 保留遮罩与图标渲染功能，React 仍复用宿主实例。
- 新增直接执行发布版面板 bundle 的回归测试，只允许宿主提供的 React 浏览器模块，并验证样式、标签页及面板注册。

## 画面与动画

- 原生多层阴影、发光、渐变、玻璃、滤镜与混合模式，避免复制大量透明图形模拟效果。
- 轻量 3D 透视、三维场景元素、高级转场、组合变换、蒙版、路径运动、跟随、连接线、错峰和弹簧动画。
- 可编辑路径、动画曲线、布局约束和文字自适应。

详见 [视觉优化](VISUAL-POLISH.md)、[动画编排](ANIMATION-CHOREOGRAPHY.md)、[布局与路径](LAYOUT-PATH-BLUR.md)。

## 设计与审片

- 项目和场景设计规范、版式适配、真实画面方案对比。
- 手工设计保护，避免自动排版改掉已确定的字段。
- 浏览器实际字体与文字边界测量，问题区域、时间定位、忽略/恢复、修复预览和复查。
- 动态有限帧抽样检查；结果明确标注采样范围。

详见 [设计工作台](DESIGN-STUDIO.md)、[自适应设计](ADAPTIVE-DESIGN.md)、[实测审片](MEASURED-REVIEW.md)。

## AI 工作效率与审美约束

- 按任务读取相关对象、依赖、素材与设计约束，操作参数按需查询。
- 在独立快照批量预演，先看前后画面与校验结果，再采用；保留生成的元素 ID，支持撤销。
- 按实际改动选择检查范围，重复预演复用结果。
- 项目审美简报保存受众、平台、情绪、视觉重点、字体层级和动效规则。
- 批量修改工具的序列化定义由约 30 KB 降至 1.8 KB；这是定义大小的变化，不代表所有任务的耗时或 token 消耗按同一比例下降。

详见 [AI 工作流](AI-WORKFLOW.md)。

## 工程、交付与内核

- 嵌套合成、便携工程包、代理预览、素材重链接和批量导出队列。
- 素材清晰度/字体/疑似白底检查，字幕断行与安全区建议。
- 音频源片段 LUFS/真峰值测量，以及增益、淡入淡出、配乐闪避建议。
- 导出前预检、低清样片、取消/重试和失败诊断。
- 写时复制、索引复用、事务恢复、幂等请求和字段冲突保护。

详见 [工程工作流](PROJECT-WORKFLOW.md)、[交付质量](DELIVERY-QUALITY.md)、[内核优化](KERNEL-OPTIMIZATION.md)。

## 使用与验证

运行 `npm run pack` 生成 `dist/djian-3.0.0.dspack` 和对应 SHA-256 文件，通过 DSHL 导入。构建过程包含规范自检、vendor 依赖检查和包回读校验。

验证入口：`npm run check`、`npm test`、`npm run test:visual`、`npm run test:ai-workflow`、`npm run test:ai-ui`。

有限帧检查不等于逐帧审查；源片段响度不等于最终混音响度；几何规则不能替代审美判断。导出队列和未采用的预演记录仍属于当前引擎会话。
