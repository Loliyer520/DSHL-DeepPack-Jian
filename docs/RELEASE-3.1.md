# D剪 3.1.0

新增文字与图标的原生多色渐变：2–8 色标、线性／径向填充、独立渐变描边、色标颜色/位置/角度关键帧、整体渐变运动，以及「极光渐变」「金属金」预设。

- 预览、导出和亮度遮罩读取当前渐变；透明字面与独立描边可以组合。
- 切分后保持渐变动画连续，保存、撤销和恢复保留渐变字段。
- 字面渐变统一作用于整段文字，包括强调色；字体、换行和逐字动画继续生效。
- 时间线格式升至 v21；旧项目自动迁移，旧引擎不会改写新格式。
- 内部 vendor 包升至 0.3.0，使更新包使用新的包版本及文件名。保留 3.0.1 的浏览器 SVG 渲染器打包修复。
- 新增直接解开 `.dspack` 与 vendor 压缩包、校验哈希并在受限宿主模块表中激活时间线插件的检查。

详见 [文字与图标渐变](TEXT-GRADIENTS.md) 和 [示例工程](../examples/text-gradients.json)。

验证：类型检查、单元测试、真实画面像素测试（字面、独立描边、透明色标、逐字动画、图标、亮度遮罩）、浏览器面板交互测试（编辑、关键帧、保存、撤销）、最终整合包模块加载测试。
