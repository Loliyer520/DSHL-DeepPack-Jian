# 遮罩与表面动画（2.6.0）

## 轨道遮罩

在元素样式页或视频画面页选择「轨道遮罩」的来源。Alpha 使用透明度，亮度模式为黑隐藏、白显示；支持反向和保留源画面。默认隐藏源的普通显示，但继续采样其时间、位置、旋转、缩放、路径运动和动画。源的时间区间之外为空；普通模式全隐藏，反向全显示。多个目标可共用一个源。

来源支持二维形状、纯文字、图标和图片；目标支持视频片段与元素。元素与源应在同一组，视频来源不分组。不支持嵌套轨道遮罩。图片 Alpha 读取真实像素，按原图填充方式处理。文字源按 SVG 文字排版，建议用明确字号和换行，不使用富文本、列表或自动折行；不包含文字逐字特效。遮罩采样的是基本图形，不包含来源的投影、玻璃、3D、羽化遮罩和手动变形等额外效果。

```js
{op:'updateOverlay',id:'content',patch:{trackMatte:{source:'mask',mode:'alpha',invert:false,hideSource:true}}}
```

删除源会同时解除目标引用。设 `trackMatte:null` 解除遮罩。

## 动态渐变

形状页的「渐变关键帧」可在播放头添加帧，并分别编辑该帧的颜色、色标位置、角度与缓动。填充和描边各自保存帧。分割元素会平移后半段的关键帧时间，维持画面连续。

动画通道 `gradientAngle`、`gradientShift`、`gradientHue` 分别调整角度偏移、色标位置偏移和色相偏移。样式页提供旋转与流色快捷动画。使用浏览器的 sRGB 色彩混合，透明颜色按浏览器规则插值。

## 表面扫光

样式页开启「表面扫光」，调整颜色、宽度、柔和度、角度和强度。亮带按源的 Alpha 裁切，不照亮外部空白；可与内外阴影同时使用。开启后自动插入从 0 到 1 的 `sweepProgress` 关键帧，用曲线编辑器调整节奏或往返运动。

## 动画片段复用

动画页的「我的动画片段」可以保存命名片段、更新同名片段、应用和删除。库随项目保存，可撤销。默认将保存的关键帧时间按目标时长等比缩放，并替换目标动画；「保留原节奏」保留原时间，「保留目标其他动画通道」仅覆盖同名通道。

可应用于元素、视频、音频和组合；音频仅使用音量通道，锁定轨道不能修改。保存的是关键帧与展开后的预设，不包括文字、图形、路径或外观设置。若复用扫光进度或渐变通道，应先给目标开启对应外观。每个项目最多 100 个片段。

时间线格式 v13。示例：[surface-animation.json](../examples/surface-animation.json)。验证：`npm test`、`npm run check`、`npm run test:surface`。
