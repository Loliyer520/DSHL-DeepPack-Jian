# D剪

JSON 时间线驱动的视频剪辑工具：**AI 操作剪辑**与 **WebUI 手动调整/预览**编辑同一份时间线 JSON，渲染层吃 JSON 出 mp4。最终形态为 dsh 整合包（.dspack），可被 DSHL 一键导入。

## 架构与当前界面

```
packages/
├── engine           — 时间线 schema、共享画面组件、渲染 API 与 CLI
├── client-timeline  — 当前剪辑界面：DSHL 右侧栏插件
├── client-library   — DSHL 在线素材资源库插件
├── webui            — 项目、素材、时间线和导出 API；保留旧独立界面源码
├── agent            — AI 剪辑 MCP 工具
├── mcp-library      — 在线素材搜索与导入 MCP 工具
└── pack             — manifest v5 / .dspack v3 整合包及构建脚本
examples/    — 示例时间线 JSON（引擎测试与格式文档）
```

当前产品入口是 DSHL 宿主中的「剪辑面板」，引擎服务不再提供旧独立界面。面板预览与导出共用 `engine/src/TimelineVideo.tsx`，素材地址和字体地址由使用场景提供。

编辑区采用深色预览工作台、独立播放控制和底部工具栏，素材与参数默认收起。时间线以居中的白色播放线定位，横向滚动或拖动空白处浏览画面；播放时轨道随时间移动。视频以连续缩略图展示，音频显示青色波形，字幕显示暖色文本块，重叠字幕、音频和画中画片段自动分行显示；音频与画中画的分行不改写实际轨道归属或叠放顺序。支持主轨拖动排序，画中画、字幕及音频移动和边缘裁剪，以及吸附开关和缩放。单击片段选中，双击或按 Enter 打开属性抽屉；窄屏轨道内部滚动。音频波形读取真实素材；超过 20 MB、浏览器无法解码或跨域读取失败时显示基础音频条，不影响剪辑。视频缩略图使用素材采样帧。

主轨、音频、画中画和字幕按独立模式编辑：当前类型完整展开，其他类型压缩成上方的细色条；点击底栏或细条切换模式，播放时间与缩放保持不变。再次点击当前模式打开工具列表，右侧「+」打开当前类型的添加入口。选中音视频片段后按 S 只分割该片段。

轨道模式、时间线缩放和吸附开关按会话保存在浏览器中，刷新后恢复；浏览器存储不可用时使用默认值，不影响编辑。这些视图设置不改写时间线。

每个剪辑面板独立持有播放器控制；多个会话同时挂载时，播放头、播放按钮、分割定位和快捷键只作用于所属面板。关闭其他会话的面板不会清除当前面板的播放器引用。

面板被宿主隐藏或浏览器标签页切到后台时自动暂停，返回后保留播放位置，需手动继续播放。隐藏引起的零宽度与滚动偏移变化不会被当成用户定位，长时间线恢复时重新显示播放头附近的片段。

素材库采用紧凑列表，支持按名称搜索和按视频／图片／音频筛选。文件详情与删除确认收纳在当前行，时间线正在使用的素材显示引用次数并禁用删除。批量上传显示文件进度，个别文件失败后继续上传；加载失败与上传失败分别提示，支持重新加载。音频加入时间线时保留已识别的源时长。

属性面板的数值修改在离开输入框或按 Enter 时提交，Esc 取消当前草稿；空值及超出范围的数值恢复为已保存值。片段时长最低为一帧，字幕起止时间至少相隔一帧。分割入口统一按项目帧率定位，分割后两侧至少保留一帧。

画中画的添加入口打开素材选择，可选视频或图片，默认放在右下角小窗；视频保留识别到的源时长，图片默认 3 秒。新增字幕、画中画和音频从当前播放头位置开始；上传音频保留选择文件时的落点。字幕输入支持输入法组合期间确认候选，Esc 可取消当前文字草稿。

支持变速片段分割和裁剪、滤镜、字幕动画、音量包络、撤销与历史恢复。竖屏画面会适应固定高度的预览区。手动修改串行保存；保存失败时保留修改并支持重试，浏览器允许本地存储时也会保留未保存草稿。

手动保存携带编辑基线，服务端在写入前比对当前版本。若 AI 或其他面板已修改同一时间线，停止自动覆盖并保留草稿，用户可明确选择「用本地覆盖」或「放弃本地，采用最新」；选择本地版本后仍会再次比对刚读取的版本。草稿恢复保留原基线，旧格式草稿需经过冲突选择。此机制防止面板静默覆盖并行修改，不进行自动合并；未携带基线的旧客户端仍沿用原接口。

长时间线按视野加载片段与标尺，缩略图和波形共用两个解码任务槽；离开视野的预览释放订阅并取消不再需要的任务。拖动到轨道窗口边缘可自动滚动，吸附支持片段两端并显示青色参考线；裁剪精确到帧，最短保留一帧。Esc 取消当前拖动，松开后一次提交，可撤销。

预览素材接口支持单段 HTTP 字节范围读取及 HEAD 请求，浏览器跳转时可直接读取目标位置的数据；取消读取会释放文件句柄。多个范围或无法校验的条件范围请求回退为完整响应，合法但超出文件的范围返回 416。

视频、音频或图片加载失败时，预览区显示对应素材名并提供重试和素材库入口。重试保留播放头位置，不改写时间线；替换或移除有问题的素材后自动尝试恢复预览。

聚焦剪辑面板后：空格播放/暂停，左右方向键逐帧，Shift + 方向键跳转一秒，S 在播放头处分割主轨，Ctrl/Cmd + Z 撤销。输入框与其他宿主区域保留自身快捷键。

点击播放时间可打开精确定位面板，输入秒数、分:秒、时:分:秒（可带小数），或切换到从 0 开始的帧位置。时间输入自动对齐到最近一帧，非法格式和超出片尾的输入会提示；Enter 定位，Esc 取消。定位只移动当前面板的播放头，不修改时间线。

导出面板支持进度、断线重连、错误详情、下载及重新导出。每次导出提交当前编辑快照，并绑定会话对应的素材目录；继续编辑不会修改已开始的任务。刷新页面会恢复本标签页记录的任务。服务在运行期间保留最近 20 个任务的独立下载地址；服务重启后需重新导出。

Windows 渲染优先使用已安装的 Chrome／Edge，未找到时由 Remotion 准备浏览器。自定义安装路径可通过 `DJIAN_BROWSER_EXECUTABLE` 指定；其他系统也可使用此环境变量。

Windows x64 首次渲染会自检编码器。随包编码器不能写出视频时，会检测 PATH 中的 FFmpeg，在系统临时目录建立独立运行缓存；不会覆盖项目依赖或系统安装。系统编码器只有原生 AAC 时，先无损混音再编码 AAC，并直接复制已编码的视频。也可设置 `DJIAN_RENDER_BINARIES_DIR` 指向包含 Remotion 合成器、FFmpeg、FFprobe 及所需动态库的完整目录。

## 快速验证

AI 本地生成素材后可调用 `import_asset({path: "本地绝对路径"})` 入库，不必寻找或写入引擎项目目录；小文件可使用 `base64` 与 `name`。路径上传最多 512MB，base64 最多 32MB，重名自动改名，请使用返回的实际 `name`。`asset_list` 现在返回 `{projectId, assetsDir, assets}` 对象（不再是纯数组）；`get_timeline` 额外返回 `canvas` 和 `assetsDir`，生成前先对齐画布。批量操作回传 `receipts`，含新片段 id、操作执行时的字幕索引、成功/忽略/部分成功状态。

`get_frame` 返回 `activeTextLayers` 与底部彩色像素/主色统计。文字层表示渲染器帧范围命中，并不能证明透明度、动画、遮挡后的实际可见性；亮度/彩色统计也不是字幕检测，背景会贡献像素，0 不能排除字幕。冷取帧内部允许等待 300 秒，宿主工具上限 330 秒；相同项目、时间线及时间点的进行中请求复用渲染。宽工作区无需递归搜索素材，直接引用生成文件路径入库。宿主 glob 工具并非本仓库提供，未改动其协议。

`node tests/integration/mcp-workflow.mjs` 验证真实 MCP 入库、回执与项目隔离；附加 `--render` 并准备 Chrome/Edge、FFmpeg 可验证真实合成帧和并发取帧复用。

版本历史采用说明与完整日期时间分行显示，方便区分跨天记录。恢复前先等待当前编辑保存完成；保存失败或存在未解决冲突时，保留草稿并停止恢复。恢复过程禁用重复操作。`tests/timeline-restore.test.mjs` 覆盖等待中的保存与后续编辑、保存失败重试、冲突保留草稿；此测试使用受控网络与存储，不等同于浏览器端完整恢复验收。

```sh
npm install
npm run build:engine
npm run check:timeline
npm test
npm run test:sessions
npm run test:seek
npm run test:render
npm run bundle -w @djian/client-ui-timeline
node packages/engine/bin/djian-render.mjs examples/timeline-a.json -o out/demo.mp4
```

引擎构建通过后再构建插件。快速测试覆盖视频/音频变速分割、缓动曲线连续性、逐帧裁剪、双端吸附、可见范围、预览队列、导出任务隔离及编码器缓存。`test:render` 需要 Chrome／Edge 与 PATH 中的 FFmpeg、FFprobe，会真实渲染变速视频、画中画、字幕和音频，核对全部 60 帧的素材位置、音频连续性和 H.264/AAC 输出。已在本机 DSH 0.1.5-rc.3 独立测试档案中加载当前插件，验证右侧栏注册、素材添加、字幕保存与刷新恢复、会话隔离及字幕模式收起主轨。该验证复用了本机宿主依赖，并不等同于全新机器安装验收；DSHL 导入整合包后的完整流程仍需继续验证。另已将 v1.2.16 整合包解到独立目录，按随包锁文件离线安装 706 个依赖、校验并解开 6 个 vendor 包，验证服务健康接口和 30 帧中文字幕 H.264 实际导出。此检查使用本机 pnpm 缓存、Chrome 与 FFmpeg，不代表无缓存机器或 DSHL 导入器完整验收。项目当前不包含完整关键帧曲线编辑器或协作冲突合并。

`test:sessions` 在独立临时目录启动真实 HTTP 服务，验证不同会话的素材与历史隔离、延迟上传期间切换项目、后台保存、磁盘写入失败及错误请求后的服务恢复。

`test:seek` 需要 Chrome／Edge 与 FFmpeg，在临时项目中生成 90 秒视频，以限速浏览器跳转到第 70 秒，验证目标帧已解码、服务返回非零偏移的范围数据，且未先下载完整文件。
